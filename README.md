# FoodExpress 🍔

Food Express is a modern, high-performance Food Delivery Application UI built with **Kotlin** and **XML**. The project focuses on a seamless user experience, professional design, and clean architecture using the latest Android development practices.

## 🚀 Features

- **Professional Onboarding:** Interactive Splash Screen and Start screens.
- **Authentication System:** Clean and responsive Login and Sign-up UI with Social Media integration (Google/Facebook).
- **Modern Navigation:** Implemented **Jetpack Navigation Component** with a **Bottom Navigation View** for smooth transitions.
- **Dynamic Home Screen:** Integrated a dynamic **Image Slider** to display featured food items and banners.
- **Core Modules:**
  - **Search:** Intuitive search interface for finding food.
  - **Cart:** User-friendly cart management.
  - **Profile:** Dedicated user profile section.
  - **Location:** Integrated 'Choose Location' module for delivery optimization.
- **Responsive UI:** Built with **ConstraintLayout** and **Material Design 3** to ensure compatibility across various screen sizes.

## 🛠️ Tech Stack & Libraries

- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Toolkit:** XML with **ViewBinding** (for type-safe UI interaction).
- **Navigation:** [Jetpack Navigation Component](https://developer.android.com/guide/navigation).
- **Design:** Material Design 3.
- **Third-party Library:** [ImageSlideshow](https://github.com/denzcoskun/ImageSlideshow) for the interactive banner slider.

## 🏗️ Architecture

- **Pattern:** Single-Activity Architecture.
- **UI:** Fragment-based UI management.
- **Layouts:** Optimized ConstraintLayout structures for performance.
